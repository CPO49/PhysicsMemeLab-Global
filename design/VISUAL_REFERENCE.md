# Visual Reference Notes

Reference file:
`design/references/meme-physics-archipelago.png`

## What to copy conceptually
- Bright paper-and-ocean palette
- World map with themed islands
- Sticker-like mascot and comic captions
- Paper mission cards with tape and doodles
- Clear transition from playful world to focused lab gameplay
- Learning report styled as a notebook rather than an admin dashboard

## What not to copy literally
- Any accidental distorted text in the generated reference
- Any recognizable copyrighted game character or asset
- Decorative currency/shop elements
- Exact artwork where team-owned assets are not available

## Priority order
1. Information hierarchy
2. Learning flow
3. World-map identity
4. Mascot reactions
5. Decorative meme layer

## Fidelity rule
When reference art conflicts with usability or the written design system, follow the written design system.
