# Skill and Boss System

## 67 Energy
พลังกลางของเกม เติมจากท่า 67 รัว ๆ และใช้เรียก Skill

## Demo Skill: Trajectory Vision
### Cost
Energy 100%

### Skill Sign
ประกบมือ → กางมือออก

### Effect
- แสดงวิถีโดยประมาณช่วงสั้น
- แสดงจุดสูงสุด
- ผู้เล่นยังต้องตัดสินใจยิงเอง

### Learning link
ทำให้เห็นความสัมพันธ์ระหว่างมุม ความเร็วต้น ความสูง และระยะทาง

## Skill Families
### Vision
วิถี จุดตก แรง เวกเตอร์

### Power
ความเร็วต้น อิมพัลส์ พลังงาน

### Control
เวลา แรงเสียดทาน แรงโน้มถ่วง

### Insight
เปรียบเทียบรอบก่อน ไฮไลต์ตัวแปร และ Concept Hint

## Boss System
บอสเป็นตัวละครต้นฉบับแนว absurd / brainrot-inspired

### Projectile Boss Preview
- เป้าเคลื่อนที่
- ผู้เล่นต้องคาดการณ์ตำแหน่งล่วงหน้า
- ใช้ Trajectory Vision ในเวลาที่เหมาะ

### Reward
- Boss Card
- Cosmetic
- Passive buff ขนาดเล็ก
- ปลดล็อก entry ใน Meme Codex

## Rule
บอสและสกิลทุกตัวต้องเชื่อมกับแนวคิดฟิสิกส์หรือกระบวนการเรียนรู้
