# Gesture Specification

เอกสารนี้กำหนดพฤติกรรม ไม่บังคับวิธีเขียนโค้ด

## 1. Grab–Aim–Release
### เป้าหมาย
ควบคุมมุมและความเร็วต้นของโพรเจกไทล์

### พฤติกรรม
- กำมือใกล้วัตถุ = จับ
- เคลื่อนมือออกจากจุดเริ่ม = ง้าง
- ทิศทางจากวัตถุถึงมือ = มุมยิง
- ระยะง้าง = ค่าความเร็วต้นโดยประมาณ
- แบมือ = ปล่อย

### Feedback
- เส้นเชื่อมมือกับวัตถุ
- ตัวบอกมุม
- หลอดกำลัง
- สถานะ “จับแล้ว / กำลังเล็ง / ปล่อย”

### Fallback
- Mouse drag and release
- Keyboard optional

## 2. 67 Power Pump
### เป้าหมาย
เติม Energy Meter

### ท่าหลัก
- มือสองข้างอยู่ต่างระดับ
- สลับระดับมือขึ้น–ลงต่อเนื่อง
- การสลับครบหนึ่งรอบนับเป็นหนึ่ง Pump

### หลักการนับ
- ใช้จังหวะและการสลับทิศ ไม่ใช้ตำแหน่งนิ้วละเอียด
- ป้องกันการเขย่ามั่วด้วย minimum travel และ cooldown
- เติมพลังตามจำนวน Pump ที่ตรวจจับได้
- มี visual pulse ทุกครั้งที่นับสำเร็จ

### Fallback
- กดปุ่มสลับซ้าย–ขวา
- Spacebar rhythm mode

## 3. Skill Sign
### Demo sequence
1. ประกบมือหรือให้ฝ่ามือเข้าใกล้กัน
2. กางมือออกหรือผลักมือไปด้านหน้า

### ผล
เปิด Trajectory Vision หาก Energy เพียงพอ

### UX
- แสดงภาพท่า 2 ขั้น
- แสดงสถานะทีละขั้น
- Timeout แล้วเริ่มใหม่โดยไม่ลงโทษหนัก

## 4. Safety and Accessibility
- ห้ามบังคับใช้แรงจริง
- หลีกเลี่ยงท่าที่ต้องเคลื่อนไหวรวดเร็วเกินไป
- มี Mouse/Keyboard fallback ทุกระบบ
- ไม่บันทึกหรืออัปโหลดภาพกล้อง
