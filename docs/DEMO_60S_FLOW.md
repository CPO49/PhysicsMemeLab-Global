# Demo 60 Seconds

## เป้าหมาย
ให้กรรมการเห็น Meme + Camera + Physics + Learning Measurement ภายใน 60 วินาที

## Timeline
0–5 วินาที
- World Map
- คลิก Projectile Island
- พูด: “เราเปลี่ยนท่ามีมให้เป็นการทดลองฟิสิกส์”

5–12 วินาที
- Mission Brief สั้น
- เป้าหมาย: ยิงข้ามกำแพงให้โดนเป้า
- Prediction 1 ข้อ

12–25 วินาที
- เปิดกล้อง
- กำมือ จับ ง้าง และปล่อย
- ยิงครั้งแรกพลาดหรือเกือบโดน

25–32 วินาที
- ระบบแสดงมุม ความเร็วต้น และวิถีครั้งแรก
- พูด: “ผู้เรียนเห็นผล ไม่ได้แค่แทนสูตร”

32–42 วินาที
- ทำท่า 67 รัว ๆ ปั๊มหลอดพลัง
- ทำ Skill Sign 2 ขั้น
- เปิด Trajectory Vision

42–52 วินาที
- ยิงครั้งที่สองพร้อมเส้นวิถี
- โดนเป้า

52–60 วินาที
- Concept Check + Summary
- แสดงคำทำนายก่อนเล่นและสิ่งที่เข้าใจหลังเล่น
- ปิดด้วย Boss/Skill Tree Preview

## กติกา Demo
- ห้ามเปิดด้วย Login
- ห้ามอธิบายทุกระบบ
- ต้องเห็นกล้องทำงานจริง
- ถ้ากล้องพลาด ให้ใช้ fallback ทันทีโดยไม่หยุด Demo
