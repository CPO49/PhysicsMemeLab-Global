# Game Design MVP

## Product
เว็บเกมเรียนฟิสิกส์ผ่านกล้องและ Gesture ในโลก Meme Physics Archipelago

## เป้าหมาย
ทำให้ผู้เรียนเปลี่ยนจากการจำสูตรไปสู่การทำนาย ทดลอง เปรียบเทียบ และอธิบายผล

## Core fantasy
ผู้เล่นเดินทางในอาณาจักรมีม ใช้ท่าทางจริงเพื่อทดลองฟิสิกส์ ปั๊มพลัง 67 เรียกสกิล และปลดล็อกสิ่งสะสม

## MVP ที่ทำจริง
- Projectile Island
- Basic Shot Mission
- ท่าง้างและปล่อย
- ท่า 67 ปั๊มพลัง
- Skill Sign 2 ขั้น
- Trajectory Vision
- Prediction, Compare, Concept Check, Summary

## ระบบที่เป็น Preview
- Boss Battle
- Skill Tree
- Meme Codex
- Brainrot-inspired Collection
- Momentum / Balance / Friction / Energy Islands

## Core Loop
1. ผู้เล่นเห็นโจทย์และทำนาย
2. ใช้ Gesture ยิงครั้งแรก
3. ดูผลและเปรียบเทียบ
4. ปั๊มพลัง 67
5. ทำ Skill Sign
6. เปิด Trajectory Vision
7. ยิงครั้งที่สอง
8. อธิบายสิ่งที่เปลี่ยน
9. รับผลการเรียนรู้และรางวัล

## เงื่อนไขผ่าน
- Game Goal: ยิงผ่านสิ่งกีดขวางและโดนเป้า
- Experiment Goal: ปรับมุมหรือแรงอย่างมีเหตุผล
- Concept Goal: อธิบายได้ว่ามุมและความเร็วต้นส่งผลอย่างไร

## หลักการยืดหยุ่น
- ไม่ล็อก library กล้อง
- ไม่ล็อก threshold ตัวเลข
- เปลี่ยน Gesture ได้หากตรวจจับง่ายกว่า
- UI และ flow ต้องยังสื่อความหมายเดิม
