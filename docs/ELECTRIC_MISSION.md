# Electric Mission Prototype

ด่านที่ 2 เป็นมินิเกมกฎของโอห์มที่เปิดหลังจบภารกิจ Projectile Basic Shot

## Flow

1. ผู้เล่นเรียนความหมายของ `V`, `I`, `R` หน่วยวัด และตัวอย่าง `V = 2 x 4 = 8V`
2. กด `เข้าใจแล้ว เริ่มด่าน 2` เพื่อเข้าสู่หน้าภารกิจ
3. ผู้เล่นเห็นปิกาจูอยู่กลางฉากและโปเกบอลด้านล่าง
4. กด `โยน = จับปิกาจู` เพื่อเริ่มภารกิจ
5. ตอบโจทย์ `V = I x R` จำนวน 3 ข้อ โดยพิมพ์คำตอบเอง
6. แต่ละข้อมีเวลา 20 วินาที และรับคำตอบรูปแบบ `8`, `8V` หรือ `8 V`
7. ตอบผิดหรือหมดเวลาจะเข้าสู่ฉากโดนช็อตและเริ่มใหม่ตั้งแต่ข้อ 1
8. ตอบถูกครบ 3 ข้อจะเข้าสู่ฉากจับสำเร็จแต่ยังโดนช็อต รับ 3 ดาว และกลับแผนที่

## Learning Goal

ผู้เล่นคำนวณแรงดันไฟฟ้าจากค่ากระแสและความต้านทานได้ โดยใช้ความสัมพันธ์ `V = I x R`

## Important Note

ด่านนี้เป็นส่วนขยาย prototype นอก MVP เดิมที่กำหนดให้เล่นได้เฉพาะ Projectile Island ภาพตัวละครและอุปกรณ์ที่เป็นทรัพย์สินของบุคคลที่สามต้องเปลี่ยนเป็นงานต้นฉบับหรือ asset ที่มีสิทธิ์ใช้งานก่อนเผยแพร่สาธารณะ
